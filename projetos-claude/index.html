Dicas do Claude · Projetos

Explique uma vez. O Claude lembra em toda conversa.

Um Projeto é uma pasta dentro do Claude. Tudo o que você coloca nela (quem você é, suas regras e seus arquivos) vale para todas as conversas daquele projeto. Funciona até no plano grátis, com até 5 projetos.

01 / Criar o projeto

Onde clicar

No computador, em claude.ai.

1. No menu da esquerda, clique em Projetos (ou abra claude.ai/projects).
2. Clique em Novo projeto, no canto de cima.
3. Dê um nome simples. Exemplo: Vendas.
4. Pronto: toda conversa que você abrir dentro dele já começa sabendo o que você colocou lá.
02 / Instruções do projeto

Cole isto nas instruções

Troque o que está entre [colchetes] pelo seu caso.

Eu sou [o que você faz, em 1 frase].
Meu cliente é [quem compra de você: profissão, porte, cidade].
O que eu vendo: [produto ou serviço, com o preço se for fixo].

Como escrever:
- Frases curtas, linguagem simples, sem emoji.
- Tom: [próximo e direto / formal].
- Nunca invente preço, prazo ou número. Se faltar informação, me pergunte antes.
- Quando eu pedir mensagem para cliente, entregue no máximo 5 linhas.
03 / Arquivos

Suba o que você manda toda semana

Na parte de arquivos do projeto, clique no +.

Bons arquivos para começar:
- Tabela de preços
- Perguntas que o cliente sempre faz (com as suas respostas)
- Apresentação da empresa
- 2 ou 3 mensagens suas que deram certo (para o Claude copiar o seu jeito)

Depois é só pedir, por exemplo:
"Usando a tabela de preços do projeto, responda este cliente em 4 linhas: [cole a mensagem dele]."
04 / Um projeto por assunto

Não misture tudo numa pasta só

Cada projeto tem a própria memória.

Exemplo de organização:
- Projeto Vendas: preços, propostas, respostas a cliente.
- Projeto Posts: seu jeito de escrever, temas, posts que funcionaram.
- Projeto Cliente [nome]: o que foi combinado com aquele cliente.

No plano grátis são até 5 projetos. Comece com 1, o da tarefa que você mais repete.
Antes de subir arquivo. Não coloque documento com dado pessoal de cliente (CPF, contrato assinado, dado de saúde). Troque nomes por [cliente] quando puder. Teste o projeto por uma semana com uma tarefa simples e só depois aumente.
