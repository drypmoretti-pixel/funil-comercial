Parte 03Passo a passo pra colocar no ar

1
Crie as contas e separe as chavesAs 7 ferramentas da Parte 02. Se travar em alguma, vá direto na Parte 04 e peça o passo a passo pro Claude.
2
Crie as tabelas no SupabaseNo Supabase, abra o SQL Editor, cole o bloco do final desta parte ("Pro seu programador") e rode. Ou peça pro Claude: "leia estes workflows e crie as tabelas que eles usam".
3
Importe os workflows, nesta ordemNo n8n: Workflows → Create workflow → menu "⋯" no canto superior direito → Import from file. Ordem: Revisão Humana, Pagamento, Agendamento, Webhook do Asaas e, por último, o Agente Principal.
4
Crie as credenciaisEm Credentials, crie uma de cada: Evolution API, OpenAI, Redis, Supabase, Postgres (opcional, só pro comando de limpar memória), e duas do tipo "Header Auth": uma pro Asaas (nome do cabeçalho access_token) e uma pro Cal.com (nome Authorization, valor Bearer SUA_CHAVE). Depois abra cada nó que mostra aviso vermelho e escolha a credencial.
5
Ligue as ferramentas do agenteAbra o Agente Principal. Cada ferramenta (human_handoff, gerar_link_pagamento, verificar_disponibilidade, confirmar_agendamento, reagendar_consulta, cancelar_consulta, salvar_horario_escolhido) pede qual workflow chamar. Escolha o certo na lista: é isso que dá "braço" pra IA.
6
Troque os dados da sua clínicaVeja a tabela logo abaixo. É a única parte que exige atenção de verdade.
7
Conecte o WhatsApp ao n8nNa Evolution API, na sua instância, aponte o webhook para a Production URL do nó "Webhook1" do Agente Principal (termina em /webhook/clinica-agente), com o evento de mensagem recebida ligado. Peça o passo a passo pro Claude (Parte 04).
8
Alimente a base de conhecimentoÉ onde a IA busca preço, endereço, preparo e regras da clínica, em vez de inventar. Coloque os textos na tabela clinica_conhecimento. Peça pro Claude: "transforme este documento da minha clínica em registros para a tabela clinica_conhecimento, com embeddings da OpenAI".
9
Teste, só depois ativeMande mensagem do seu próprio celular. Use o ambiente de testes (sandbox) do Asaas. Confira o checklist da Parte 05 e então ative os 5 workflows.

-- Base de conhecimento (RAG)
create extension if not exists vector;
create table if not exists clinica_conhecimento (
  id bigserial primary key, content text,
  metadata jsonb, embedding vector(1536)
);
create or replace function match_documents (
  query_embedding vector(1536), match_count int default null, filter jsonb default '{}'
) returns table (id bigint, content text, metadata jsonb, similarity float)
language plpgsql as $$
#variable_conflict use_column
begin
  return query
  select id, content, metadata, 1 - (clinica_conhecimento.embedding <=> query_embedding) as similarity
  from clinica_conhecimento
  where metadata @> filter
  order by clinica_conhecimento.embedding <=> query_embedding
  limit match_count;
end;
$$;

-- Segurança: dados de paciente. Ligue o RLS em tudo.
-- (a chave service_role, usada só dentro do n8n, ignora o RLS)
alter table customers enable row level security;
alter table clinica_pagamentos enable row level security;
alter table clinica_agendamentos enable row level security;
alter table customer_consulting enable row level security;
alter table follow_up_queue enable row level security;
alter table clinica_conhecimento enable row level security;
  • Use a chave service_role do Supabase somente dentro do n8n. Nunca em página, app ou chat.
  • O agente calcula as datas a partir do fuso America/Sao_Paulo e fecha sábado e domingo. Ajuste no nó "Prepare Agent Context1" se a sua clínica atende diferente.

Parte 04Peça ao Claude o passo a passo

É o que eu faço quando preciso configurar uma ferramenta que não conheço: em vez de assistir uma videoaula inteira, peço pro Claude me guiar uma etapa de cada vez. Troque o que está entre colchetes e cole.

1. Evolution API (WhatsApp)

Cole no Claude · Evolution API
Quero conectar um número de WhatsApp ao meu n8n usando a Evolution API.

Meu cenário: [meu n8n é self-hosted / n8n cloud]. A Evolution API [já está instalada / ainda não].

Me guie em português simples, UMA etapa por vez, e espere eu confirmar antes de seguir:
1. Como instalar ou contratar a Evolution API.
2. Como criar a instância e ler o QR Code com o celular da clínica.
3. Onde pegar a URL e a API key, e como criar a credencial no n8n.
4. Como apontar o webhook da instância para a Production URL do meu nó Webhook (termina em /webhook/clinica-agente), com o evento de mensagem recebida.
5. Como testar mandando uma mensagem do meu celular.

Regra: não peça a minha chave no chat. Crie uma pasta de segurança com um arquivo .env e me diga onde colar.

2. Asaas (pagamento)

Cole no Claude · Asaas
Quero configurar o Asaas para cobrar o sinal da consulta pelo meu agente no n8n.

Me guie em português simples, UMA etapa por vez:
1. Como criar a conta e usar o ambiente de testes (sandbox) antes do ambiente real.
2. Onde gerar a chave de API e como criar a credencial "Header Auth" no n8n (o cabeçalho é access_token).
3. Como configurar o webhook de pagamento confirmado apontando para a Production URL do workflow "Webhook do Asaas" (termina em /webhook/asaas-pagamento-confirmado).
4. Como testar uma cobrança no sandbox, do link até a confirmação.
5. Como trocar do sandbox para o ambiente real com segurança.

Regra: não peça a minha chave no chat. Use um arquivo .env.

3. Agenda (Cal.com ou Google Agenda)

Cole no Claude · Agenda
Quero configurar a agenda do meu agente de clínica no n8n. O workflow "Agendamento" usa o Cal.com.

Me guie em português simples, UMA etapa por vez:
1. Como criar o tipo de evento no Cal.com (duração da consulta) e achar o eventTypeId.
2. Como gerar a chave de API (v2) e criar a credencial "Header Auth" no n8n (Authorization: Bearer ...).
3. Onde colocar o eventTypeId nos nós "Buscar Horarios", "Criar Reserva" e "Registrar Agendamento".
4. Como testar: consultar horários livres, reservar, remarcar e cancelar.

[Opcional] Se eu preferir o Google Agenda: me diga quais nós do workflow "Agendamento" eu preciso trocar e como manter as mesmas 5 ações (verificar, salvar, confirmar, reagendar, cancelar).

Regra: não peça a minha chave no chat. Use um arquivo .env.
Dica de ouro Peça sempre "uma etapa por vez e espere eu confirmar". Assim o Claude não despeja 30 passos de uma vez e você acompanha na tela.
