A ideiaA proposta nasce da conversa, não de um modelo velho

Proposta genérica perde venda porque não fala do problema do cliente. O Claude Code lê duas coisas: o que o cliente disse e como a sua empresa se apresenta. Com isso ele monta uma proposta sob medida, em HTML, e você exporta para PDF.

PROPOSTA GENÉRICA

  • Mesmo texto para todo cliente
  • Fala do seu serviço, não da dor dele
  • Demora horas para ajustar

Etapa 1Crie a pasta e o briefing

Crie uma pasta (ex.: proposta-cliente), abra o Claude Code nela e salve um arquivo briefing.md com o que foi dito na reunião. Pode ser a transcrição ou suas anotações.

Crie o arquivo briefing.md nesta pasta com este conteúdo e organize em: quem é o cliente, a dor principal (com as frases dele), o que ele quer resolver, prazo desejado e orçamento mencionado.

Etapa 2Ensine a sua identidade uma vez

Crie um arquivo identidade.md com cores, fonte, serviços e preços. Você faz isso uma vez e reaproveita em todas as propostas.

COPIE E COLE NO CLAUDE CODE
Crie o arquivo identidade.md com: nome da empresa, cores (hex), fonte, tom de voz, meus serviços com o que entrega cada um e o preço de cada um.
Meus dados: [NOME DA EMPRESA], [CORES], [SERVIÇOS E PREÇOS].

Etapa 3Peça a proposta

COPIE E COLE NO CLAUDE CODE
Leia briefing.md e identidade.md. Monte proposta.html em uma única página rolável, com estas seções: 1) o problema do cliente nas palavras dele, 2) a solução que proponho, 3) o que será entregue, 4) prazo, 5) investimento (use só os preços de identidade.md), 6) próximos passos com data. Use a minha identidade visual e linguagem simples.
COMO FICAO Claude Code cria o arquivo proposta.html na pasta. Abra no navegador para ver. Se algo estiver errado, peça o ajuste em uma frase: “deixe o investimento em destaque”, “encurte o item 2”.

Etapa 4Revise como cliente

COPIE E COLE NO CLAUDE CODE
Releia a proposta como se fosse o cliente. Aponte: o que está confuso, qual objeção ele provavelmente teria e se o preço está claro. Depois ajuste o proposta.html com o que você apontou.

Etapa 5Exporte para PDF
