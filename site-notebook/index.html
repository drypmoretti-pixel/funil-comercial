Seus arquivos viram um site com uma frase

O passo a passo pra transformar as planilhas e documentos do seu projeto num painel que o time abre pelo link, com o Gemini Notebook do Google.

O que é

Desde 16/11/2026, o Gemini Notebook (o caderno de inteligência artificial do Google, que antes se chamava NotebookLM) monta um site interativo a partir dos arquivos que você coloca nele. Você escreve o que quer no chat e ele devolve uma página pronta: um painel de projeto, um painel de vendas ou um material de treinamento.

Passo a passo (10 minutos)

  1. Entre em notebook.google.com no computador, com a sua conta Google (é pra maiores de 18; o app de celular ainda não tem).
  2. Crie um caderno novo e coloque os arquivos do projeto: a planilha de tarefas, a ata da última reunião, o documento com os prazos.
  3. No chat do caderno, cole o pedido abaixo.
  4. Quando o site aparecer, abra numa aba nova e confira cada número com a planilha.
  5. Compartilhe o link com o time no lugar de mandar a planilha no grupo.
PEDIDO PRONTO
Me faz um site pra acompanhar este projeto. Quero ver no topo quanto já foi feito (em porcentagem), o que está atrasado ou em risco, e embaixo a lista de tarefas com o responsável e o prazo de cada uma. Use só as informações dos arquivos deste caderno. Escreva em português.

Outros 3 pedidos prontos

PEDIDO PRONTO
Me faz um site com o resumo de vendas do trimestre: total vendido, meta, quanto falta e os 5 maiores negócios abertos. Use só a planilha deste caderno.
PEDIDO PRONTO
Me faz um site de treinamento pra vendedor novo, com as perguntas que o cliente mais faz e a resposta de cada uma, a partir destes documentos. No fim, um teste rápido de 5 perguntas.
PEDIDO PRONTO
Me faz um site pra apresentar esta proposta ao cliente: o problema dele, o que vamos entregar, as etapas com datas e o investimento. Use só os documentos deste caderno.

O cuidado que ninguém comenta

  • A própria tela avisa: ele pode errar. Confira os números antes de mandar o link.
  • Antes de colocar arquivos com dados de cliente, veja se a sua empresa permite usar essa ferramenta.
  • Se o arquivo de origem está desatualizado, o site também vai estar.
